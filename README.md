# Steam Success Chaser — Releases

Ce dépôt ne contient que les installateurs de **Steam Success Chaser**, une application de bureau pour chasser les succès Steam. Le code source est privé.

## Installer

Télécharge `SteamSuccessChaser-Setup-<version>.exe` dans la [dernière release](https://github.com/BrasseurTristan/steamsuccesschaser-releases/releases/latest) et lance-le.

L'application n'est pas signée : Windows SmartScreen affiche « Windows a protégé votre ordinateur ». Clique sur « Informations complémentaires », puis « Exécuter quand même ».

## Mises à jour

L'application installée vérifie les nouvelles versions dans ce dépôt au démarrage, puis toutes les 6 h. Elle les télécharge en arrière-plan et les installe à la fermeture.
